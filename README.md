# gta6-cover-art-02

A GTA 6 cover art maker and editor that runs in the browser, built as a
make.fun bounty entry.

Open the app, start from a sample scene or your own image, and shape it
into cover art in three shapes: landscape cover, square, and portrait.
The editor state, cover rendering, and shot list live in plain JavaScript
modules, with no build step.

## Layout

- `app/index.html`: the app entry
- `app/src/`: editor modules (cover rendering, main flow, shots, state)
- `app/samples/`: sample scenes to start from
- `screenshots/`: the cover, the editor, and the square and portrait results
- `serve.ts`: a small local server for trying the app
